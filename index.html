Privacy Policy

1. Overview

This Privacy Policy describes how GuideMe (“GuideMe,” “we,” “us”) handles information when you use the GuideMe Chrome Extension (“Extension”) and related services.

GuideMe helps employees learn and complete tasks in complex business applications through contextual, step-by-step workflow guidance. The Extension may provide workflow discovery, workflow recording, step-by-step guidance, screenshots associated with workflow steps, contextual UI element highlighting, and a Chrome Side Panel interface.

This page is provided for users and organizations evaluating or using GuideMe. By using the Extension, you acknowledge this Privacy Policy.

2. Information We Process

GuideMe processes information necessary to provide its functionality. The types of information depend on how your organization configures GuideMe and how you use the Extension.

User activity

GuideMe may process workflow-related user activity on supported business application pages, such as:

  • clicks
  • text input actions
  • selections
  • checkbox and radio interactions
  • navigation between supported application pages
  • workflow recording actions

This information is used to create, store, and provide workflow guidance.

Website content

On configured business application pages, GuideMe may access relevant page content and UI elements to:

  • identify UI elements
  • determine element names and labels
  • record workflow interactions
  • highlight relevant elements during guidance

Screenshots

During workflow recording, GuideMe may capture screenshots. Screenshots are associated with workflow steps and used to provide visual guidance.

GuideMe is designed to avoid intentionally capturing passwords and other sensitive input values where possible. However, we cannot guarantee that sensitive information will never appear in a screenshot—for example, if it is visible elsewhere on the page or captured incidentally during recording.

3. How We Use Information

We use collected information only to:

  • record workflows
  • store workflows
  • provide step-by-step workflow guidance
  • display screenshots
  • highlight relevant elements
  • allow authorized users to create, manage, and use workflows
  • operate and improve the GuideMe service

We do not use this information for advertising, we do not sell it, and we do not use it for creditworthiness or lending purposes.

4. Data Sharing

GuideMe does not sell user data.

We may share or disclose information with service providers that help us operate GuideMe—for example, hosting or storage providers—solely to provide the service on our behalf and subject to appropriate contractual protections where applicable.

5. Remote Code

The GuideMe Chrome Extension does not execute remotely hosted JavaScript or other executable code. Extension executable code is packaged with the Extension as distributed through the Chrome Web Store.

GuideMe may communicate with backend services to retrieve and store application data (such as workflows). This communication is not remote code execution.

6. Chrome Extension Permissions

The Extension requests certain Chrome permissions to function. Below is a summary of why these permissions are used:

activeTab
Allows GuideMe to interact with the tab you are actively using when you start or use a workflow, so guidance can apply to the page you are working on.
Host permissions
Allows GuideMe to run on business application websites your organization has configured, so it can record and display guidance on those pages.
scripting
Allows GuideMe to inject scripts on permitted pages to identify UI elements, highlight them during guidance, and support workflow recording and playback.
sidePanel
Allows GuideMe to show its interface in the Chrome Side Panel while you work in the application.
storage
Allows GuideMe to store Extension settings and local data needed for the Extension to operate on your device.
tabs
Allows GuideMe to detect which tab is active and coordinate guidance when you move between pages or tabs in supported applications.
webNavigation
Allows GuideMe to respond when you navigate between pages in a supported application, so guidance can stay in sync with your location in the app.

7. Data Retention and Deletion

Workflow data and associated information may be retained while your organization uses GuideMe and as needed to provide the service.

Users or organizations may request deletion of their data through the GuideMe service or support process. We will handle such requests in accordance with applicable agreements and operational procedures.

8. Security

We use reasonable technical and organizational measures designed to protect information processed by GuideMe. No method of transmission or storage is completely free of risk, and we cannot guarantee absolute security.

9. Children’s Privacy

GuideMe is intended for business and workplace use. It is not directed at children, and we do not knowingly collect personal information from children.

We may update this Privacy Policy from time to time as GuideMe evolves. When we make changes, we will revise the “Last updated” date at the top of this page. We encourage you to review this page periodically.
